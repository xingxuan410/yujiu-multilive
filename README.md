# 宇宙人的监控室 🛸

> 一个用 Electron 封装的 B 站多开直播监控室。
> 纯纯用 **许愿机** 捏出来的小玩意，大家轻喷。

## ✨ 主要功能

- **监控室多开直播** 🖥️
  - 同窗口自适应网格，多路直播同时看；
  - 直播房间预热池：点开秒开，缓冲时就已经是全屏；
  - 自动网页全屏 + 自动收起评论区（走页面原生热区点击，不搞 CSS 硬藏）；
  - 房间分组（**分组可折叠/展开**）、静音、💬 评论栏一键开合；
  - “正在观看”列表同样可以一键折叠；
  - 侧边栏支持自定义半透明背景图（`resource/sidebar.jpg`）；
  - 画质随缘，命好不卡。
- **开播提醒** 🔔
  - 定时轮询 B 站开播状态（间隔可调）；
  - 开播右下角弹窗 + 系统通知，点弹窗直达直播间；
  - 支持关闭窗口最小化到托盘，挂机摸鱼两不误。

## ⚠️ 重要提醒

- **多开直播 = 多倍带宽 + 多倍解码**，CPU / GPU / 网络都会更吃力；
- 同一 WiFi 下设备多了，**多开很可能让整个网络变卡**，建议：
  - 少开几路，画质从"原画"降到"高清/流畅"；
  - 不看的房间及时关掉；
  - 能插网线就插网线。
- 卡不是你的错，是这垃圾小玩意和 B 站网页都挺能吃资源的。

## 🚀 快速开始

**免安装版（推荐）**：到本仓库的 [Releases](../../releases) 页面下载 `yujiu-ultilive-0.1.1-portable.exe`，双击即可运行，无需安装任何环境。数据（含登录状态）保存在 exe 同目录的 `data\` 文件夹里。

开发运行：

```bash
npm install
npm start
```

测试 / 打包命令：

```bash
npm run smoke          # GUI 冒烟自测
npm run smoke:headless # 无头自测
npm run dist           # 打包 Windows 便携版
```

## 🐣 第一次使用提示

- **第一次启动会有点慢**：需要加载直播页面和预热缓存，属于正常现象，之后会快很多；
- **极少数情况第一次启动会黑屏/界面没加载完整**：便携版首次解包较慢，**重启一次应用即可**；
- **登录**：如果需要登录，可以点击下面【消耗电池】相关入口，B 站会自动拉起登录窗口，登录后会被记住；
- **防火墙**：第一次运行如果出现各种奇怪 bug，一般是因为**防火墙未放行**，在防火墙里允许本应用联网后**重启即可**。

## 🧰 技术栈

Electron + 原生 Node（无打包器，无框架，主打一个能跑）。主进程管窗口/轮询/通知，`WebContentsView` 负责多路直播间网格。
